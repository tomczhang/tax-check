# 星财富（复星国际证券）月结单解析器

解析器实现：`src/lib/parsers/xingcaifu.ts`。本文记录月结单版式调研结论和解析规则，供后续维护参考。

## 支持材料

复星国际证券（FOSUN INTERNATIONAL SECURITIES，CE 编号 AAF432）App「星财富」导出的 PDF 月结单，两类账户版式一致：

- **现金账户**（表头 `Account Type: Cash Account 現金`）
- **保证金账户**（`Margin Account 保証金`），持仓表多出按贷率/可按贷值两列，利息总结多出融资利率列

两类月结单共用同一解析器，账户编号（賬戶編號）计入记录 id 以区分来源。PDF 有内嵌文本层、未加密，用 pdfjs 提取带坐标的文本 token 后按行解析，不涉及 OCR。

## 月结单结构（按出现顺序）

| 区块 | 解析用途 |
| --- | --- |
| 結單概要 | 账户编号、账户类型、结单日期区间（用于持仓 asOf） |
| 當月賬戶結餘 | 不解析 |
| 證券組合 | 月末持仓（结存股数 > 0 才收录） |
| 債券組合 | 跳过 |
| 當月資金提存交易 | 分红、预扣税、红利手续费、货币基金利息、基金申赎资金侧 |
| 當月證券提存交易 | 基金申赎份额侧、账户间转仓 |
| 成交信息 | 股票买卖逐笔（含费用明细） |
| 未交收證券交易 | 待结算交易，按编号与成交信息去重后并入 |
| 利息總結 | 不解析（融资利息不属于应税收入） |

区块标题在每个续页重复出现，解析按标题切换状态机，跨页条目（如费用块在次页收尾）依赖标题重复维持状态。

## 关键解析规则与坑

### 股票交易：股数/单价以小计行为准

成交信息每笔交易的版式：证券名称行（可能折行，可能粘连在交易行的「內容」列）→ 交易行（交易日、交收日、編號、B/S、Agent/Principal、股数、单价、清算金额）→ 若干「股数 单价」小单行 → 费用块（經紀傭金/證監會費/交易活動費/交收费/平臺使用費/Other Fee/Foreign Fee）。

- 单笔成交时，交易行内联股数单价与紧随的重复小单行一致，取哪个都行。
- **多小单合并成交时，交易行的内联股数只是第一笔小单**（例如 CHA 买入行内联 49 股，实际小计 200+100+134+235+82，合计 800 股；TCOM 卖出行内联 21 股，实际合计 67 股）。规则：费用块前最后一条小单行才是总数。第一笔小单因坐标与交易行同一基线，会被行分组并进交易行，靠上述规则兜住。
- 费用不逐行累加，直接取 `|清算金额| − 股数×单价`（清算金额已含全部费用），避免漏掉版式之外的费用种类。

### 证券代码提取

交易行「內容」列是「代码+中文名+英文名」粘连文本（如 `METAMeta Meta`、`AAPL蘋果 Apple`、`FIGFigma Figma`）。提取顺序：中文边界切割 → 大小写边界切割（`([A-Z]{2,5})(?=[A-Z][a-z])`）→ 纯 ASCII 首词。内联内容为空时用交易行之前的名称行。

### 货币基金申购/赎回

基金申赎不在成交信息里，由两条记录配对而成：

- 资金提存行：`資金提取Fund Subscription For HK0000499787 FUND @..., ReferenceId=89091`（金额）
- 证券提存行：`證券存入 HK0000499787.FUNDFund Subscription For ... ReferenceId=89091`（份额）

按账户编号 + ReferenceId 配对，申购生成 `acquire`（成本=出资金额），赎回生成 `sell`（收入=到账金额）。配对失败时金额按 0 处理并给出 warning。证券提存条目是单行（日期、編號、摘要、数量），摘要折行时续行拼回。

### 账户间转仓：配对抵消

同一客户现金账户 ↔ 保证金账户互转时，两份月结单各出现一条 `客戶轉倉轉出` 摘要（措辞有 `不同資金帳號` 和 `同一資金帳號` 两种，英文措辞同样不可靠），**靠数量符号判断方向**：负数为转出本账户、正数为转入本账户。代码取摘要中最后一个 `#CODE` 或 `CODE.US` 模式。

同一日期、同一证券、同一币种、数量绝对值相等的转入/转出互为配对，配对后两条都剔除。原因：计算层按券商+币种+代码重放成本，若保留转出（消耗成本）+ 转入（零成本补回），成本链会断。未配对的转入保留并提示补录原始成本。

### 分红与利息的三种格式

均出现在资金提存区块，按 日期+币种+代码 聚合成一条 DividendIncome：

1. `紅利入帳 USD0.06/股 #名称(代码) Div-...` + `股息稅 #名称(代码)(30.00%)...` + `紅利手續費 #代码DIV. HANDING CHARGE FOR #名称(代码)`
2. `資金存入Corporate action dividend total cash in (22.10 for #[UNH.US])` + `資金提取Corporate action dividend tax cash out (...)`
3. `資金存入Div of #NVDA @0.25/shs` + `資金提取Withholding Tax for #NVDA`

货币基金 `資金存入Interest Payment for IE0004514828` 计为利息收入（securityName 标注「货币市场基金利息」），无预扣税。

### 明确不计入的资金流水

银行存入（TRF DEP SCB）、换汇（FX ...）、Cash reward、佣金返还（Commission Rebate）、IPO 手续费返还（CASHBACK OF IPO）、账户间资金转移（Cash Transfer Deposit/Withdrawal）——汇总进解析完成提示的忽略条数，不进税额。

### 持仓

每个账户只保留其最新一份结单的持仓：月结单列示全部持仓，空仓证券不再出现，若按「每个证券取最新一条」会把已清仓证券残留为当前持仓。

## 验证记录（2026-09）

用 21 份真实月结单（现金账户 2025/08–2026/08、保证金账户 2026/01–08）验证：

- 133 笔股票交易、84 笔基金申赎、32 条分红/利息、11 条当前持仓，无警告、无成本缺口。
- 逐笔核对多小单合并交易：CHA 800 股（买入 9,046.78 / 卖出 9,581.55 与结单清算金额一致）、TCOM 卖出 67 股、BABA 卖出 30 股、DRAM 买入 100 股、META 买入 15 股，费用均与费用块合计一致。
- 重放数量与 2026/08 结单持仓一致：MSFT 91、META 15、NVDA 110、DRAM 100、AAPL 15、QQQ 4、QQQM 25。
- 1 月 26 日现金→保证金转仓（AAPL/META/MRVL/MSFT/QQQ/TCOM 及 4 只基金）全部配对抵消，无残留转仓记录。
- 2026 年 FIFO 试算 69 笔已实现交易，正常产出资本利得与分红税额。

## 已知边界

- 港股交易、拆并股、债券交易在所持样本中未出现，版式未覆盖；遇到时解析器会以 info 级提示「未识别的证券提存记录」或缺少代码/股数的 warning，需要按实际样本补充规则。
- 摘要换行续接依赖行分组的 y 坐标容差（2.2pt），其他年份模板若行距变化可能需要调整。
